# Formula Student Electric - Смета проекта

Подробная документация по смете для разработки электрического болида Formula Student.

## Структура документации

- **Обзор бюджета** - Сводная информация по всем категориям
- **Силовая установка** - Электромотор, инвертор, аккумуляторная батарея (заполняется позже)
- **Защитное оборудование** - Экипировка водителя и системы безопасности
- **Электроника** - Системы управления, датчики, ECU
- **Шасси и механика** - Рама, подвеска, тормоза, колеса
- **Инструменты** - Оборудование мастерской
- **Регламенты** - Ссылки на FSG/FSE Rules и требования

## Быстрый старт

### Просмотр документации онлайн

Документация автоматически публикуется на GitHub Pages при пуше в main ветку.

### Локальный просмотр

```bash
# Открыть документацию в браузере
open build/html/index.html
```

Или перейдите в папку `build/html/` и откройте `index.html` в браузере.

### Настройка GitHub Pages

1. Зайдите в Settings → Pages
2. Source: выберите "Deploy from a branch"
3. Branch: выберите "gh-pages" → "/ (root)"
4. Сохраните
5. Пушьте в main ветку — документация обновится автоматически в ветке gh-pages

### Редактирование

Все исходные файлы находятся в папке `source/`:

```
source/
├── index.rst                  # Главная страница
├── budget_overview.rst        # Обзор бюджета
├── powertrain.rst             # Силовая установка (TBD)
├── safety_equipment.rst       # Защитное оборудование ✓
├── electronics.rst            # Электроника ✓
├── chassis_mechanical.rst     # Шасси и механика ✓
├── tools.rst                  # Инструменты ✓
└── regulations.rst            # Регламенты ✓
```

### Сборка документации

После внесения изменений в `.rst` файлы:

```bash
make html
```

Документация будет пересобрана в `build/html/`.

### Очистка

Для очистки собранной документации:

```bash
make clean
```

## Формат документов

Документация написана в формате **reStructuredText (.rst)**.

Основные элементы:

```rst
Заголовок
=========

Подзаголовок
------------

**Жирный текст**

*Курсив*

.. note::
   Заметка

.. warning::
   Предупреждение

.. list-table:: Название таблицы
   :header-rows: 1
   :widths: 25 25 25 25

   * - Колонка 1
     - Колонка 2
     - Колонка 3
     - Колонка 4
   * - Значение 1
     - Значение 2
     - Значение 3
     - Значение 4
```

## Приоритеты закупок

### Высокий приоритет (необходимо сразу):
1. Защитное оборудование (обязательно по регламенту)
2. Инструменты для работы
3. Основные компоненты шасси

### Средний приоритет:
1. Электроника и системы управления
2. Датчики и измерительное оборудование

### Низкий приоритет (после определения спецификаций):
1. Электромотор
2. Инвертор
3. Аккумуляторная батарея
